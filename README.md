### [Crisis NLP: Disaster Tweet Triage](https://github.com/saurabhburnwal/crisis-nlp-triage)
`Python` `scikit-learn` `XGBoost` `SHAP` `NLP`

- 5-fold stacking ensemble of Logistic Regression, Random Forest and GPU-accelerated XGBoost.
- Tuned Random Forest with GridSearchCV and TreeSHAP, cutting nodes **4.23x** at **86.73% precision**.

🔗 [Code](https://github.com/saurabhburnwal/crisis-nlp-triage)
